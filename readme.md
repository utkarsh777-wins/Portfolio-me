### ❖ Featured Iteration: deskBuddy
`deskBuddy` is an ambient hardware edge node built to eliminate digital friction. 

* **Logic:** Proximity-triggered listening via **HC-SR04** ultrasonic sensors.
* **Audio:** **I2S Digital Microphone** input with high-fidelity output for real-time technical assistance.
* **Intent:** A dedicated hardware assistant that answers technical doubts without the need for tab-switching.
