### ❖ Featured Project: [deskBuddy-v1](https://github.com/utkarsh777-wins/deskBuddy-v1) ↗
An ambient hardware edge node built to eliminate digital friction via a Finite State Machine architecture and on-device intelligence.

* **Core:** `ESP32 DevKit V1`
* **Visuals:** `GC9A01 Round LCD` — dynamic expressions & clock UI
* **Sensing:** `HC-SR04` (proximity) · `PIR Sensor` (motion) · `Light Sensor` (ambient adaptation)
* **Intelligence:** `TinyML Wake Word` for low-power voice activation
* **Audio:** `I2S Digital Microphone` + `PAM8403 Amplifier`

No tab switching. Proximity gesture or wake word triggers high-speed technical assistance through an ambient interface.

### ↳ The Build Details
* **Neural Canvas** — custom network simulation built on `performance.now()` with Lissajous-style node drift; reacts dynamically to scroll depth across six section clusters.
* **Neuron Theme Toggle** — a live mini neural canvas fixed bottom-right; proximity-aware, floats clear of the SCROLL indicator and footer copyright automatically.
* **Dark / Light Mode** — auto-detects `prefers-color-scheme`; manual override stored in `localStorage`. Smooth crossfade transition on swap.

* **Editorial Aesthetics** — `Instrument Serif` + `DM Sans`, warm gold palette across both themes.
